# 黄庆旭个人主页 · 中英文版

这是可直接上传到 GitHub Pages 的完整静态网站，附带中文内容编辑器。默认首页为英文，点击顶部 **中文 / EN** 可切换到同一页面的另一种语言。

## 日常更新：不需要写代码

1. **先完整解压 ZIP**，用 Chrome、Edge 或 Firefox 打开 `editor.html`。不要在压缩包内直接打开。
2. 在左侧选择栏目，修改右侧中文和 English 字段。点击 **新增条目** 添加论文、项目、课程、荣誉或学生信息；也可复制、移除、上下调整顺序。顶部 **撤销操作** 可恢复最近 25 次操作。
3. 点击 **预览网站**，切换预览语言和页面，检查内容。然后点击 **导出网站 ZIP**，解压下载的新包，将包内文件上传到 GitHub 仓库根目录并提交。

下次继续编辑时，打开**最新导出包**里的 `editor.html`。它已经包含你的最新资料。

### 常用操作

- **修改简介或招生信息**：选择“简介与招生”。简介支持空行分段。
- **新增论文**：选择“论文”→“新增条目”，填写标题、作者、期刊和年份；需要在首页展示时，勾选“在首页展示为代表论文”。论文页面自动按年份倒序，同一年内按编辑器中的顺序展示。
- **添加科研项目**：选择“科研项目”，填写项目名称、日期、承担角色、资助机构和编号；系统按“主持”和“合作”分组。
- **添加学术动态等新栏目**：选择“自定义内容”，指定放在哪个页面，填写双语标题和正文。新栏目显示在该页面末尾。
- **更换照片**：在“基本资料”底部上传 JPG、PNG 或 WebP 图片，最大 4 MB。
- **调整其他内容顺序**：使用“上移 / 下移”。论文会先按年份分组；项目、课程、学生等会先按各自类别分组。
- **填写 DOI**：只填 `10.1038/xxxxx` 这样的 DOI，不要包含 `https://doi.org/` 前缀。

中英文内容由你分别填写，编辑器不会自动翻译。某一种语言留空时，网页会显示另一种语言的内容。正文是纯文本，空行分段；不需要填写 HTML。

## 草稿与备份

- 修改后自动保存到当前浏览器的本机草稿。重新打开时，如草稿与文件不同，可选择“恢复草稿”或“使用当前文件”。
- 本机草稿不会同步到 GitHub，也不会跨电脑同步。若浏览器无法保存，页面会提示下载备份。
- 点击“下载资料备份”保存 JSON。换电脑或换浏览器后，点击“导入资料备份”恢复。尚未填写完整的条目也可备份。
- **JSON 备份只包含资料；发布请使用“导出网站 ZIP”。** 保存完整 ZIP 也可以保留内容、头像、页面和编辑器。
- 编辑器不会直接覆盖你磁盘上的旧文件，也不会直接更新线上网站；上传并提交新导出包后，GitHub Pages 才会更新。

## 上传到 GitHub Pages

1. 创建公开仓库。个人主页通常命名为 `你的用户名.github.io`，例如用户名为 `example` 时仓库名为 `example.github.io`。
2. 将解压后的网站文件上传到仓库根目录。根目录应直接看到 `index.html`，而不是 ZIP 或额外一层文件夹。保留 `assets`、`data` 和 `zh` 文件夹。
3. 在仓库 **Settings → Pages** 中，选择 **Deploy from a branch**，分支选择 `main`，目录选择 **/(root)**，保存。
4. 等待 GitHub 完成发布，然后打开 `https://你的用户名.github.io/`。

也支持普通项目仓库；页面全部使用相对路径，可放在 `https://你的用户名.github.io/仓库名/` 下。无须填写 GitHub 用户名到代码里，无须安装依赖。

更新时上传新导出包中的文件并覆盖同名文件。**仅上传 `data/content.json` 不会更新已经生成的网页。**

GitHub 官方说明：https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 文件说明

| 文件或目录 | 用途 |
| --- | --- |
| `index.html` 等根目录 HTML | 六个英文页面 |
| `zh/` | 六个对应的中文页面 |
| `editor.html` | 内容管理入口，双击即可使用 |
| `data/content.json` | 全部中英文内容的可读数据源 |
| `data/content.js` | 编辑器离线加载资料的副本，由导出或构建自动生成 |
| `assets/style.css` | 网站样式 |
| `assets/engine.js` | 中英文页面模板 |
| `assets/schema.js` | 编辑表单字段和资料校验 |
| `assets/editor.js`、`editor.css` | 编辑器逻辑与样式 |
| `assets/package.js`、`bundle.js` | 离线导出完整 ZIP 所需的工具与资源 |
| `assets/portrait.*` | 个人照片 |
| `build.cjs` | 可选的命令行构建脚本 |
| `CONTENT-NOTES.md` | 资料来源及英文整理说明 |

## 习惯直接改代码时

可编辑 `data/content.json` 中的资料，再在此文件夹执行：

```sh
node build.cjs
```

需要 Node.js 18 或更新版本，不需要 `npm install`。它会同时生成十二个页面，刷新编辑器资料及离线导出资源。修改模板、CSS 或编辑器代码后，也运行一次，保证下一次从编辑器导出的文件包含代码变化。

不要直接修改生成的 HTML 或 `data/content.js` 来维护内容，这些文件会在下次导出时重新生成。无需命令行时，始终使用 `editor.html` 即可。
